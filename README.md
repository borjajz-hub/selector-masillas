# Selector de masillas

App web instalable (PWA) para elegir la masilla adecuada (Roberlo, SINNEK o 3B) según la marca, el soporte, el tipo de daño, el tamaño de la reparación, la temperatura, la exposición a agentes corrosivos y la imprimación.

**Abrir / instalar:** https://borjajz-hub.github.io/selector-masillas/

- **Android (Chrome):** menú ⋮ → *Instalar aplicación* o *Añadir a pantalla de inicio*.
- **iPhone (Safari):** botón Compartir → *Añadir a pantalla de inicio*.

Funciona sin conexión una vez abierta.

Solo incluye masillas con ficha técnica disponible: las del catálogo de Roberlo España con TDS publicada (roberlo.com, 23/11/2026), cinco de SINNEK (PP/1440, PP/9010, PP/9507, PP/6208, PP/7832; Ed. 002) y dos de 3B · Plus Europaint Color España (Baja Densidad y Universal Plus; Ed. 5, enero 2025). Si la marca elegida no tiene ninguna masilla que valga para la reparación, la app lo indica y recomienda la mejor de otra marca. Antes de aplicar cualquier producto, consulta su ficha de seguridad y la etiqueta. Los consejos marcados como "buena práctica de taller" no vienen en las fichas.
