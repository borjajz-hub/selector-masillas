# Selector de masillas Roberlo

App web instalable (PWA) para elegir la masilla Roberlo adecuada según el soporte, el tipo de daño, el tamaño de la reparación, la temperatura, la exposición a agentes corrosivos y la imprimación.

**Abrir / instalar:** https://borjajz-hub.github.io/selector-masillas/

- **Android (Chrome):** menú ⋮ → *Instalar aplicación* o *Añadir a pantalla de inicio*.
- **iPhone (Safari):** botón Compartir → *Añadir a pantalla de inicio*.

Funciona sin conexión una vez abierta.

Solo incluye las masillas del catálogo de Roberlo España que tienen ficha técnica (TDS) publicada. Datos tomados de las TDS oficiales de roberlo.com (23/11/2026). Antes de aplicar cualquier producto, consulta su ficha de seguridad y la etiqueta. Los consejos marcados como "buena práctica de taller" no vienen en las fichas.
